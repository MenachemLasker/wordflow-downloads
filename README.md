# Wordflow for Windows

גרסה עדכנית: **0.2.0**

## הורדה

- [מתקין Windows המומלץ (EXE)](https://raw.githubusercontent.com/MenachemLasker/wordflow-downloads/main/Wordflow-Windows-Setup.exe)
- [מתקין MSI חלופי](https://raw.githubusercontent.com/MenachemLasker/wordflow-downloads/main/Wordflow-Windows-x64.msi)
- [קובץ SHA-256 לאימות](SHA256SUMS.txt)

## מה חדש ב־0.2.0

- תרגום אוטומטי עברית ↔ אנגלית באמצעות Microsoft Translator.
- אפשר להזין מילה או ביטוי רק בשפה אחת ולהשלים את השפה החסרה.
- הגדרות מאובטחות למפתחות ElevenLabs ו־Microsoft Translator.
- תרגומים קיימים אינם נדרסים.
- פריטים ללא תרגום מלא אינם נכנסים לתרגול.

## הערת אבטחה

האפליקציה עדיין אינה חתומה בתעודת Code Signing. Windows SmartScreen עשוי להציג אזהרה; במקרה כזה יש לבחור **„מידע נוסף” → „הפעל בכל זאת”** רק אם הקובץ הורד מהמאגר הרשמי הזה.
