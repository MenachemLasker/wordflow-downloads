# Wordflow for Windows

גרסה עדכנית: **0.2.1** — Windows x64

## הורדה

- [מתקין Windows המומלץ (EXE)](https://github.com/MenachemLasker/wordflow-downloads/raw/refs/heads/main/Wordflow-Windows-Setup.exe)
- [מתקין MSI חלופי](https://github.com/MenachemLasker/wordflow-downloads/raw/refs/heads/main/Wordflow-Windows-x64.msi)
- [קובץ SHA-256 לאימות](SHA256SUMS.txt)
- [פרטי מקור ובנייה](PROVENANCE.txt)

## מה חדש ב־0.2.1

- תוקנה חסימת ניגון קובצי אודיו מקומיים ב־Windows.
- שגיאות בניגון האודיו מוצגות בנפרד משגיאות ביצירת האודיו אצל הספק.
- תרגום אוטומטי עברית ↔ אנגלית באמצעות Google Cloud Translation.
- אפשר להזין מילה או ביטוי רק בשפה אחת ולהשלים את השפה החסרה.
- הגדרות מאובטחות למפתחות ElevenLabs ו־Google Cloud Translation.
- תרגומים קיימים אינם נדרסים; פריטים ללא תרגום מלא אינם נכנסים לתרגול.

## אימות ומגבלות

המתקינים נבנו ב־Windows ועברו בדיקות אוטומטיות. התקנה, הפעלה וניגון בפועל במחשב Windows של המשתמש עדיין דורשים אימות.

## הערת אבטחה

האפליקציה עדיין אינה חתומה בתעודת Code Signing. Windows SmartScreen עשוי להציג אזהרה; במקרה כזה יש לבחור **„מידע נוסף” → „הפעל בכל זאת”** רק אם הקובץ הורד מהמאגר הרשמי הזה.
